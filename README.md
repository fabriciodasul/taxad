# Indicadores Financeiros

Uma página web simples para acompanhar indicadores econômicos brasileiros e consultar cotações de ações.

## O que o projeto faz

- Exibe a meta Selic, o IPCA mensal e o dólar PTAX com dados do Banco Central do Brasil.
- Permite buscar ações brasileiras por ticker, como `PETR4` e `VALE3`.
- Atualiza os dados de forma assíncrona usando JavaScript e APIs públicas.

## APIs utilizadas

- [Banco Central do Brasil — SGS](https://api.bcb.gov.br/)
- [brapi.dev](https://brapi.dev/)

## Tecnologias

HTML, CSS e JavaScript, com `fetch`, `async` e `await`.

## Sobre mim

Durante a faculdade, atuei principalmente com criação de produtos e inovação, além de QA. Este projeto reúne esses interesses: uma solução simples, orientada a dados e pensada para entregar uma experiência clara ao usuário.

## Como usar

Abra o projeto no navegador. Os indicadores são carregados automaticamente; para consultar ações, informe um ou mais tickers separados por vírgula e clique em **Buscar** ou pressione Enter.
